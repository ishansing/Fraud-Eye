# Fraud Netra

This glossary defines the domain language for the current prototype and the safety-gated SPECv3 target.

## Language

**Document**:
A submitted source file considered for screening.
_Avoid_: Image, upload (when referring to the document itself)

**Page**:
A single logical sheet or rendered view within a document.

**Anomaly**:
A specific observation that may warrant review; it is evidence, not a conclusion that a document is fraudulent.
_Avoid_: Fraud finding

**Screening verdict**:
A profile-bounded signal: `INCONCLUSIVE` unless an approved, evaluated profile supports `PASS` or `FLAGGED`. It is never a credit, lending, onboarding, identity, or KYC decision.
_Avoid_: Approval, rejection, authenticity proof

**Authenticity score**:
A profile-specific estimate of document integrity, calibrated only for a defined population and evaluation. It is not a universal probability or proof that a document is genuine.

**Circuit-breaker rule**:
A deterministic finding that overrides a model score in an approved profile. It is still a screening signal and must not trigger a consequential decision.

**Perceptual layout hash (`pHash`)**:
A visual-layout fingerprint that can identify similar layouts. Similarity alone does not prove document reuse, tampering, or fraud.

**Synthetic document**:
A document whose visible content is substantially or entirely generated by a synthetic system.

**Tampered document**:
A source document whose content has been altered, including through image editing, PDF manipulation, text splicing, or generative inpainting.

**Heatmap overlay**:
A visual estimate of regions that a validated localization model considers potentially manipulated.
_Avoid_: Proof of tampering

**Ephemeral retention**:
A declared, bounded lifetime for data before deletion. A 24-hour lifetime is not zero retention; deletion behavior must include derived files, logs, backups, and crash artifacts.
