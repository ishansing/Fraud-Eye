# Normative specification pointer

The normative Fraud Netra target specification is [`../../SPEC.md`](../../SPEC.md), adapted from
the supplied [`../../SPECv3.md`](../../SPECv3.md). SPECv3 is the long-term target only; its
real-document, retention, persistence, authentication, and binary-verdict features do not
override the current synthetic-only, memory-only, loopback, `INCONCLUSIVE` safeguards.
`SPEC.md` carries the stable requirement IDs and phased gates.

Use this file as the product-document index; do not copy the normative requirements here.
Testable acceptance criteria are maintained separately in
[`acceptance-criteria.md`](acceptance-criteria.md).
