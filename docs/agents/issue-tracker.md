# Issue tracker

This repository tracks implementation work in local Markdown slices under `docs/work/`.

- Use `docs/work/ISSUE-<nnn>.md` as the issue source for project changes.
- Link code reviews to the relevant slice and normative requirements in `SPEC.md`.
- There is no configured external issue tracker or repository remote. Do not infer an
  external project from the local directory name.
- Add an external tracker here only after the repository owner provides its canonical URL.
